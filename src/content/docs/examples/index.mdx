The live example is [`jsudc-example`](https://github.com/digital-cube/jsudc-example): a Fastify
server with thirteen collections over every source (Postgres, a directory, three HTTP APIs, a YAML
menu) and a React app that is `UdcDataView` in a shell. Every renderer on this site's home page is
a screenshot of it.

Its `/examples` route shows the same companies view entered at different layers of
`@jsudc/react` (see [Theming](/concepts/theming/)). Each one has a page here, with the host code it
takes.
