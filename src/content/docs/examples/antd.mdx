The [UI kit layer](/concepts/theming/#2-the-ui-kit-your-own-components) again, with Ant Design:
`@jsudc/ui-antd` maps the kit's primitives to `antd` components, and `ConfigProvider` themes them:

```tsx
import { antdKit } from "@jsudc/ui-antd";

<ConfigProvider theme={theme}>
  <UdcProvider client={client} renderers={renderers} kit={antdKit}>
    <UdcDataView collection="companies" />
  </UdcProvider>
</ConfigProvider>;
```

The example will get a route that shows the companies with it. Follow the
[roadmap](/packages/#roadmap).
