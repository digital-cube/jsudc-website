`<UdcDataView collection="books" />` asks a UDC server what `books` is and draws it: search,
filter chips and a filter builder, paging, inline edits, the schema editor, and one tab per
renderer the collection's `view.yaml` lists. The server here is the one from
[A server in ten lines](/get-started/server/), running on port 5100.


The data view fills its parent as a flex column, so give the parent a height, as the
`div` above does. Show another collection by changing the prop; key the view by collection when
one page switches between them.

## Only the renderers you use

Each renderer is its own subpath, so a page bundles, and you install the peers of, only the ones
you register:

<Code code={renderersTsx} lang="tsx" title="src/renderers.tsx" />

Pass `renderers={renderers}` to `UdcProvider` instead of `RENDERERS`. A view that lists a
renderer you did not register shows the others.

## Restyling

`@jsudc/react/styles.css` is compiled with every class prefixed, so it cannot collide with your
own Tailwind or CSS. Its colours and fonts are CSS variables (`--primary`, `--background`,
`--border`, …, with a `.dark` set): redefine them in your stylesheet, after the library's, to
make the data view yours.
