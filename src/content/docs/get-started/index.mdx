## What you need

- **Node 24.** The server quick starts run TypeScript as it is (`node server.ts`): Node 24 strips the
  types itself.
- **A package manager.** The pages say `npm`; pnpm, yarn and bun work the same.
- **Postgres**, only for the full stack. The other two keep their rows in memory or ask a server.

Every code block on these pages is a file the site's build compiles against the published
packages, and the server quick starts are started and asked for their rows, so what you copy
works with the version on npm.
