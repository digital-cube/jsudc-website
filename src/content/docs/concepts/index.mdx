A UDC (Universal Data Collection) is data described once, in three small files, and served and
drawn from that description. The server reads the files and answers one protocol; the client
asks the protocol and draws whatever the view describes. Neither side has code for a particular
collection.

These pages explain the parts in the order you meet them. The [Reference](/reference/) has every
key of every file and message, generated from `@jsudc/core`.
