Describe a collection. Get the whole data UI.

A collection is three small files: its fields in schema.json, how it looks in view.yaml, where its rows live in source.yaml. The server answers for it over one JSON protocol, and the React data view draws it with search, filters, inline edits and a schema editor.

schema.json the fields

{
  "fields": {
    "name": { "type": "string" },
    "description": { "type": "text" },
    "language": { "type": "string" },
    "stargazers_count": {
      "type": "integer", "min": 0 },
    "pushed_at": { "type": "datetime" },
    "topics": { "type": "string_array" },
    "archived": { "type": "bool" }
  }
}

view.yaml how it is shown

default_renderer: cards
available_renderers: [cards, table, chart]
search:
  fields: [name, description]
filters:
  - { field: language, kind: select }
  - { field: archived, kind: bool }
columns:
  - { field: name, pin: left, width: 220 }
  - { field: language, render: badge }
chart_options: { type: pie,
  category_field: name, value_field: stargazers_count }

kind: http_api

One protocol, both sides

@jsudc/core is the contract: every request and every answer is a Zod-validated envelope. The server imports it to check what arrives; the client imports it to check what comes back. Swap either side for your own and the other does not notice.

Every action is POST /udc/<action>: describe, list, read, mutate, and schema edits that add, change or retire a field at runtime.

@jsudc/reactasks

server.ts
import Fastify from "fastify";
import { createDispatcher, loadRegistry, makeSource, udcPlugin } from "@jsudc/server";

const registry = loadRegistry("./collections", (asset, reg) =>
  makeSource(asset, { registry: reg, env: process.env }),
);
const app = Fastify();
await app.register(udcPlugin, { dispatcher: createDispatcher(registry), registry });
await app.listen({ port: 5100 });
  1. npm install @jsudc/server @jsudc/core fastify zod
  2. Put a books/ directory under collections/ with a view.yaml, a schema.json and a source.yaml of kind: memory.
  3. Run it, then ask it: curl localhost:5100/udc/list -d '{"collection":"books"}'
